# Domain docs

This repository uses a **single-context** layout.

* `CONTEXT.md` at the repository root contains the ubiquitous language, domain model, and architectural rules for the entire project.
* `docs/adr/` contains Architectural Decision Records (ADRs).

## For Agents

* **Read:** When asked to learn about the domain or architecture, read `CONTEXT.md`.
* **Write:** When making architectural decisions or establishing new domain concepts, update `CONTEXT.md` and create a new ADR in `docs/adr/`.
